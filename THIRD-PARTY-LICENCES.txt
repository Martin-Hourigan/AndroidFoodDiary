Fonts bundled with this app
===========================

Eight typefaces ship inside the APK, in app/src/main/res/font. Seven are under
the SIL Open Font License 1.1, whose one condition is that this licence text
travels with them — which is why this file exists. The eighth has its own,
much shorter terms.

Copyright lines below are taken from each font's own name table, not from
memory, so they say what the font files themselves say.

  archivo.ttf
      Copyright 2020 The Archivo Project Authors
      https://github.com/Omnibus-Type/Archivo
      SIL Open Font License 1.1

  cardo.ttf
      Copyright (c) 2002-2011, David J. Perry
      SIL Open Font License 1.1

  eb_garamond.ttf
      Copyright 2017 The EB Garamond Project Authors
      https://github.com/octaviopardo/EBGaramond12
      SIL Open Font License 1.1

  fraunces.ttf
      Copyright 2020 The Fraunces Project Authors
      https://github.com/undercasetype/Fraunces
      SIL Open Font License 1.1

  grenze_gotisch.ttf
      Copyright 2020 The Grenze Gotisch Project Authors
      https://github.com/Omnibus-Type/Grenze-Gotisch
      SIL Open Font License 1.1

  im_fell_english.ttf
  im_fell_english_sc.ttf
      Copyright 2007 Igino Marini (www.iginomarini.com)
      With Reserved Font Name "IM FELL English Roman" / "IM FELL English SC"
      SIL Open Font License 1.1

  kingthings_petrock.ttf
      Kingthings Petrock, Kevin King, 2006.
      Not OFL. See design/fonts/LICENCE-kingthings.txt — the author grants free
      use for any purpose, asking only that the .ttf itself is left unmodified.
      It is bundled unmodified.

Note on Reserved Font Names: the OFL forbids distributing a *modified* version
of a font under its reserved name. Every file here is the original, unmodified
release, so nothing in this app engages that clause.
