# Kingthings Petrock

The typeface used in Oblivion's menus. Kevin King, Exeter, 1999.

Kept here rather than in `app/src/main/res/font/` because no style has been
chosen yet — nothing in the app references it. If the Cyrodiil direction is
picked, these move into `res/font/` (the filenames are already in the lowercase
form Android requires) and `LICENCE-kingthings.txt` goes with them.

## Licence

From the author's own EULA, shipped in the download and kept alongside:

> All the fonts currently published on my website (www.kingthingsfonts.co.uk)
> are free for you to use for any purpose you wish. Please do not change my
> original font files (.TTF).

So: free to bundle in the app, commercial use included. The one condition is
that the .ttf files are not modified — which rules out subsetting them to save
APK space. At 29 KB each that isn't a cost worth arguing with.

Some font repositories label this "personal use only". That contradicts the
licence the author ships with the font, which is the one that governs.
